## 独立本地链与浏览器检查

独立启动 Hardhat 节点，执行现有 `deploy` 脚本并配置前端合约地址。使用 Chrome 与 `agent-browser`：

1. 无钱包查询部署脚本的演示产品，显示制造商、当前所有者、未激活状态和 720 天时长。
2. 查询旧产品后注册新产品，页面正确刷新到新产品。
3. 制造商发起转给零售商，切换账号接收；零售商发起转给消费者，消费者接收后保修激活。
4. 消费者申请，服务中心批准并完成维修，页面显示 Serviced、服务结果及处理人/时间。
5. 新建第二笔申请并批准后转售，二手消费者接收；保修日期、计数和已批准申请保留，服务中心仍可完成该申请。
6. 二手消费者申请第三笔并获批后，页面显示 `3 / 3` 和 `Claim limit reached`。
7. 切换模拟钱包到主网 ID 后，写连接被拒绝并提示本地网络与 RPC。
8. 390px 和 1280px 宽度下文档宽度均等于视口，无横向滚动；页面未记录未捕获 JavaScript 异常。

浏览器写入使用临时 EIP-1193 测试桥接，选择 Hardhat 已解锁测试账号并通过真实 RPC 发送交易；不是模拟合约响应，但也不是 MetaMask 等扩展钱包的签名弹窗测试。临时桥接、测试节点和开发服务器在检查结束后清理，不作为产品功能提交。
